# v1.2.0 Release Notes

## Highlights

- Added GitHub Actions CI for backend tests and frontend lint/build.
- Added portable backend environment configuration with `.env.example`.
- Added H2-backed test profile for CI-friendly backend tests.
- Added server-side item pagination, sorting, and richer filtering.
- Updated the item management UI with status filters, sort controls, page size selection, and accessible pagination.

## Backend

- `GET /api/items` now returns `PageResponse<ItemDTO>` inside the existing `ApiResponse` envelope.
- This is a breaking response-shape change from the earlier raw list response.
- Supported filters: `keyword`, `categoryId`, `locationId`, `status`.
- Supported pagination and sorting: `page`, `size`, `sort`, `direction`.
- Keyword search now checks item name and description.
- Status filters support `normal`, `expiring`, and `expired`.
- Upload and static resource paths now share configurable upload path behavior.

## Frontend

- Item list consumes paged API data.
- Filter changes reset to the first page.
- Added page summary, previous/next buttons, and page-size control.
- Selection control is now a semantic button with an accessible label.
- Batch action bar adapts better on mobile screens.

## Verification

- Backend: `mvn clean test`
- Frontend: `npm run lint`
- Frontend: `npm run build`

## Notes

- Local Node.js is still below the declared `>=20.19.0` engine in this machine, so npm shows `EBADENGINE` warnings during install. CI uses Node.js `20.19.0`.
- npm audit still reports dependency advisories. Dependency security upgrades should be handled in a focused follow-up to avoid unplanned breaking changes.
