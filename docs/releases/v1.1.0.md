# Sort Manager v1.1.0

## Highlights

- Installed and used the Superpowers workflow for planning, execution, and verification discipline.
- Added a written implementation plan at `docs/superpowers/plans/2026-07-13-v1-1-quality-upgrade.md`.
- Cleared the frontend ESLint gate.
- Added backend Bean Validation and domain-level safety checks.
- Added backend tests for category, item, location, and upload validation.
- Hardened image uploads with MIME type and extension allowlists.
- Added project-level setup, development, and quality gate documentation.
- Added startup preflight checks to `start.bat`.

## Verification

Required checks for this release:

```powershell
cd backend
mvn clean test
```

```powershell
cd frontend
npm run lint
npm run build
```

## Known Remaining Work

- No browser-level end-to-end tests yet.
- Item lists are still loaded without pagination.
- Production deployment settings are not yet separated from local development settings.
- npm audit currently reports dependency vulnerabilities inherited from the frontend dependency graph; assess and upgrade separately to avoid accidental breaking changes.
