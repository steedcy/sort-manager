# Sort Manager v1.3.0

发布日期：2026-07-20

## 主要变更

- 前端升级到 Vite 7、Axios 1.18 和 React Router 7.18，`npm audit` 为 0 漏洞。
- CORS 改为环境变量精确白名单，默认仅允许本机 Vite 地址。
- 引入 Flyway V1/V2，支持空库初始化和已有 v1.2 数据库 baseline 接管。
- Hibernate 默认由 `update` 改为 `validate`，避免生产结构被隐式修改。
- 新增三条真实全栈 Playwright 流程和 MySQL 8.4 CI 作业。
- 后端产物固定为 `target/manager.jar`，本地一键启动不再依赖版本化文件名。

## 升级说明

1. 备份现有 MySQL 数据库。
2. 检查 `category.name` 没有重复值。
3. 在 `.env` 中配置数据库凭据和 `APP_CORS_ALLOWED_ORIGINS`。
4. 启动后端；现有非空库会建立 Flyway baseline 1 并执行 V2。
5. 确认 `flyway_schema_history` 最新成功版本为 2，再启动前端。

若 V2 因重复分类名称失败，请先人工确认合并策略；迁移不会自动删除或合并业务数据。
