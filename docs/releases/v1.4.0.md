# Sort Manager v1.4.0

发布日期：2026-07-21

## 主要变化

- 新增家庭、OWNER/MEMBER 账号、BCrypt 密码与首次 OWNER 安全初始化。
- 新增短时 JWT Access Token、可撤销且单次轮换的 Refresh Token，以及登录失败限流。
- 所有业务数据、分页、统计、关联对象和图片访问按当前家庭隔离。
- API 统一升级到 `/api/v1`，新增登录、刷新、退出、当前用户和家庭成员管理接口。
- PC 端新增响应式登录、会话恢复、角色感知导航和家庭成员管理界面。
- Flyway V3 将 v1.3 存量数据安全归入默认家庭，并将分类名称唯一性限定在家庭内。
- CI 与 Playwright 改为真实认证流程，并加入移动视口登录冒烟。

## 升级步骤

1. 停止 v1.3 服务并同时备份 MySQL 数据库与上传目录。
2. 拉取 v1.4 代码，复制并补全 `.env.example` 中的新配置。
3. 生成至少 32 字节的 `APP_JWT_SECRET`；设置强 `APP_BOOTSTRAP_PASSWORD`，不要提交或记录这些值。
4. 已有 v1.3 数据库保持 `FLYWAY_BASELINE_ON_MIGRATE=false`，使用非 root 应用账号启动打包后的后端 JAR。
5. 确认 `flyway_schema_history` 最新成功版本为 4，且现有分类、位置、物品均已关联默认家庭。
6. 使用首次 OWNER 登录，创建家人账号并验证看板、物品和图片。
7. 生产环境仅通过 HTTPS 反向代理开放，显式配置 CORS 来源并保持 MySQL 端口不公开。

MySQL DDL 不保证事务回滚。若 V3 升级失败，应停止服务、保留日志并恢复升级前备份，不要在半迁移结构上继续写入。

## 兼容性说明

- v1.3 客户端使用的 `/api/*` 无鉴权接口不再兼容，前后端必须同步升级。
- Refresh Token 在使用后立即失效；客户端必须保存刷新响应中的新 Token。
- 原 `/uploads/**` 公共图片地址改为受保护文件 API，浏览器通过认证请求加载。
- v1.4 不包含小程序客户端、批量导入或密码自助找回；这些属于后续版本。
