# Sort Manager v1.5.0

发布日期：2026-07-21

## 主要变化

- 新增最多 100 行的原子批量录入 API，支持逐行预检、字段错误和家庭关联校验。
- PC 端新增“入库托盘”批量工作台，支持粘贴 Excel/WPS、导入 CSV、下载模板、草稿恢复和整批提交。
- 新增原生微信小程序基础版：账号登录、会话刷新、统计总览、物品查询、快速录入和退出。
- CI 增加批量录入回归、小程序脚本/工具测试以及桌面和移动端流程验证。
- 后端与前端版本统一升级到 1.5.0；本版本不新增数据库迁移，最新 Flyway 版本仍为 4。

## 升级步骤

1. 备份 MySQL 数据库和上传目录，停止 v1.4 服务。
2. 拉取 v1.5 代码并执行后端测试、打包和前端 `npm ci`/`npm run verify`。
3. 启动后端，确认 `/api/v1/health`、登录、单条录入和批量预检正常。
4. PC 端使用模板完成一次预检与录入；批量提交失败时不会保存任何一行。
5. 如需小程序，复制 `miniapp/config.example.js` 为 `miniapp/config.js`，填写个人服务器 HTTPS API 地址，并在微信公众平台登记 request 合法域名。

## 兼容性与限制

- v1.4 Web/API 客户端继续兼容；新增接口仍要求 Bearer Token。
- CSV 使用 UTF-8；`.xlsx`、公式、图片批量上传、OCR/条码识别不在本版本范围。
- 小程序基础版使用账号密码登录，不包含微信一键登录、离线写入和消息通知。
- 小程序配置、AppID、Token 和服务器证书私钥不得提交到 Git。
