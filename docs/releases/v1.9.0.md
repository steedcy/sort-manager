# v1.9.0

## 变更

- 移除独立的微信小程序客户端及其 CI 检查任务；项目以响应式 Web/PWA 作为唯一客户端。
- 新增 Web 图书 EAN-13 扫码入口，使用 ZXing 兼容更多浏览器；HTTP 局域网访问时会明确提示摄像头需要 HTTPS。
- 新增服务端 ISBN 标准化、Google Books 与 Open Library 图书信息查询，以及图书元数据保存字段。

## 升级说明

- 小程序目录和微信公众平台配置不再需要维护。
- 手机摄像头扫码必须通过受信任的 HTTPS 域名访问 Web/PWA；直接使用 HTTP 局域网 IP 时，浏览器不会开放摄像头权限。
