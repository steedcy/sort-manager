# v2.0.0

## 变更

- 后台界面统一优化为移动优先的 H5 体验，新增“我的”页面、账户信息卡片，以及家庭成员和家庭运营入口。
- 二级页面增加返回操作；退出登录改为二次确认，避免误退出。
- 登录页精简为账号密码登录，采用系统名称、版本号、背景图与半透明毛玻璃登录卡片。
- 后端、CI 与 Docker/NAS 构建运行环境统一升级至 JDK 26；Spring Boot 升级至 3.5.16，以支持 Java 26 字节码。
- Windows 本地启动脚本为 Java AF_UNIX 内部套接字设置专用临时目录，规避受影响环境的回环连接失败。

## 已知事项

- 图书扫码可打开摄像头；ISBN 外部数据查询的完善工作暂不包含在本版本范围内。
